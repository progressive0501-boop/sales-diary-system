## ESLint設定方針

### 使用パッケージ

```bash
eslint-plugin-vitest    # Vitestのアンチパターン検出
```

### 主要ルール

| ルール | 設定 | 理由 |
|--------|------|------|
| `vitest/expect-expect` | error | アサーションのないテストを禁止（`expect(true).toBe(true)` 等も検出） |
| `vitest/no-disabled-tests` | warn | `test.skip` / `describe.skip` の残留を警告 |
| `vitest/no-focused-tests` | error | `test.only` / `describe.only` のコミット禁止 |
| `vitest/valid-expect` | error | `expect()` の不正な使い方を検出 |
| `vitest/no-identical-title` | error | 同一スコープ内でのテスト名重複を禁止 |
| `vitest/consistent-test-it` | warn | `test` / `it` の表記を `test` に統一 |
| `@typescript-eslint/no-explicit-any` | error | `any`型の使用禁止 |

### 設定ファイル（`eslint.config.mjs` 抜粋）

```js
import { FlatCompat } from '@eslint/eslintrc'
import vitest from 'eslint-plugin-vitest'

const compat = new FlatCompat()

export default [
  ...compat.extends('next/core-web-vitals', 'next/typescript'),
  {
    files: ['**/*.test.ts', '**/*.test.tsx'],
    plugins: { vitest },
    rules: {
      ...vitest.configs.recommended.rules,
      'vitest/expect-expect': 'error',
      'vitest/no-focused-tests': 'error',
      'vitest/consistent-test-it': ['warn', { fn: 'test' }],
    },
  },
]
```

## テスト方針

### テストの種類

| 種類 | 説明 | 対象 |
|------|------|------|
| 機能テスト | 各機能が仕様どおりに動作するかを検証 | 全機能 |
| 異常系テスト | 不正な入力・操作に対して適切にエラーが返るかを検証 | 全API・全画面 |
| 権限テスト | ユーザー種別ごとに操作制限が正しく機能するかを検証 | 全API |
| 画面テスト | 画面の表示・操作・遷移が仕様どおりかを検証 | 全画面 |

### 合否基準

- **合格（Pass）：** 期待結果と実際の結果が一致している
- **不合格（Fail）：** 期待結果と実際の結果が一致しない
- **対象外（N/A）：** テスト環境の制約などで実施不可
