| `@typescript-eslint/no-explicit-any` | error | `any`型の使用禁止 |

## SCR-001：ログイン画面

### 概要
システムへのログイン画面。メールアドレスとパスワードで認証する。

### 表示条件
- 未ログイン状態でシステムにアクセスしたとき

### 画面レイアウト

```
┌─────────────────────────────────────────┐
│              営業日報システム             │
│                                         │
│  メールアドレス                          │
│  [ email@example.com               ]    │
│                                         │
│  パスワード                              │
│  [ ●●●●●●●●                        ]    │
│                                         │
│         [ ログイン ]                     │
└─────────────────────────────────────────┘
```

### 項目定義

| 項目名 | 種別 | 必須 | バリデーション |
|--------|------|------|----------------|
| メールアドレス | テキスト入力 | ○ | メール形式 |
| パスワード | パスワード入力 | ○ | 8文字以上 |
| ログインボタン | ボタン | — | — |

### アクション

| アクション | 処理 | 遷移先 |
|-----------|------|--------|
| ログインボタン押下（成功） | 認証・セッション生成 | SCR-002 ダッシュボード |
| ログインボタン押下（失敗） | エラーメッセージ表示 | SCR-001（再表示） |

### エラーメッセージ

| 条件 | メッセージ |
|------|-----------|
| メールアドレス未入力 | メールアドレスを入力してください |
| パスワード未入力 | パスワードを入力してください |
| 認証失敗 | メールアドレスまたはパスワードが正しくありません |

## SCR-002：ダッシュボード（日報一覧）

### 概要
日報の一覧を表示する。営業は自分の日報のみ閲覧。上長は担当営業全員の日報を閲覧できる。

### 表示条件
- ログイン済み状態

### 画面レイアウト

```
┌───────────────────────────────────────────────────────┐
│  営業日報システム          [ユーザー名] [ログアウト]    │
├───────────────────────────────────────────────────────┤
│  日報一覧                          [ + 新規日報作成 ]  │
│                                                       │
│  絞り込み：[営業名 ▼] [年月 ▼] [ 検索 ]              │
│                                                       │
│  ┌────────────────────────────────────────────────┐   │
│  │ 日付       │ 営業名   │ 訪問件数 │ コメント有無 │   │
│  ├────────────────────────────────────────────────┤   │
│  │ 2026-04-13 │ 山田 太郎│ 3件      │ あり        │   │
│  │ 2026-04-12 │ 山田 太郎│ 2件      │ なし        │   │
│  │ 2026-04-11 │ 山田 太郎│ 4件      │ あり        │   │
│  └────────────────────────────────────────────────┘   │
│                          [ < 前へ ]  [1/5]  [ 次へ > ] │
└───────────────────────────────────────────────────────┘
```

### 項目定義

| 項目名 | 種別 | 説明 |
|--------|------|------|
| 営業名フィルター | セレクトボックス | 上長のみ表示。自分配下の営業から選択 |
| 年月フィルター | セレクトボックス | 年月で絞り込み |
| 検索ボタン | ボタン | フィルター条件で一覧を再取得 |
| 新規日報作成ボタン | ボタン | 営業ユーザーのみ表示 |
| 日付 | テキスト | 日報の対象日（YYYY-MM-DD形式） |
| 営業名 | テキスト | 上長ログイン時のみ表示列 |
| 訪問件数 | テキスト | その日のVISIT_RECORD件数 |
| コメント有無 | テキスト | COMMENTが1件以上あれば「あり」 |

### アクション

| アクション | 処理 | 遷移先 |
|-----------|------|--------|
| 行クリック | 日報詳細を表示 | SCR-004 日報詳細・編集画面 |
| 新規日報作成ボタン押下 | 新規作成画面を表示 | SCR-003 日報作成画面 |

### 表示制御

| ユーザー種別 | 表示範囲 |
|-------------|---------|
| 営業 | 自分が作成した日報のみ |
| 上長 | 配下の営業全員の日報 |

## SCR-003：日報作成画面

### 概要
当日分の日報を新規作成する。訪問記録は複数行追加可能。

### 表示条件
- 営業ユーザーでログイン済み
- 当日分の日報が未作成

### 画面レイアウト

```
┌─────────────────────────────────────────────────────┐
│  営業日報システム        [ユーザー名] [ログアウト]   │
├─────────────────────────────────────────────────────┤
│  日報作成                                            │
│  対象日：2026-04-13（本日）                          │
│                                                     │
│  ▼ 訪問記録                                         │
│  ┌──────────────────────────────────────────────┐   │
│  │ # │ 顧客名               │ 訪問内容           │   │
│  ├──────────────────────────────────────────────┤   │
│  │ 1 │ [株式会社A ▼       ] │ [テキストエリア  ] │   │
│  │ 2 │ [株式会社B ▼       ] │ [テキストエリア  ] │   │
│  └──────────────────────────────────────────────┘   │
│                          [ + 訪問先を追加する ]      │
│                                                     │
│  ▼ 今日の課題・相談（Problem）                       │
│  ┌──────────────────────────────────────────────┐   │
│  │                                              │   │
│  │                                              │   │
│  └──────────────────────────────────────────────┘   │
│                                                     │
│  ▼ 明日やること（Plan）                              │
│  ┌──────────────────────────────────────────────┐   │
│  │                                              │   │
│  │                                              │   │
│  └──────────────────────────────────────────────┘   │
│                                                     │
│              [ キャンセル ]  [ 保存する ]             │
└─────────────────────────────────────────────────────┘
```

### 項目定義

| 項目名 | 種別 | 必須 | バリデーション |
|--------|------|------|----------------|
| 対象日 | テキスト（表示のみ） | — | 当日日付を自動セット |
| 顧客名（訪問記録） | セレクトボックス | ○ | 顧客マスタから選択 |
| 訪問内容（訪問記録） | テキストエリア | ○ | 最大1000文字 |
| 訪問先を追加するボタン | ボタン | — | 行を1件追加 |
| Problem | テキストエリア | — | 最大2000文字 |
| Plan | テキストエリア | — | 最大2000文字 |

### アクション

| アクション | 処理 | 遷移先 |
|-----------|------|--------|
| 訪問先を追加するボタン押下 | 訪問記録の入力行を1行追加 | SCR-003（再描画） |
| 訪問記録行の削除ボタン押下 | 対象行を削除（1行以上を保持） | SCR-003（再描画） |
| 保存するボタン押下（成功） | DAILY_REPORT・VISIT_RECORDをDB保存 | SCR-004 日報詳細画面 |
| 保存するボタン押下（失敗） | エラーメッセージ表示 | SCR-003（再表示） |
| キャンセルボタン押下 | 入力内容を破棄 | SCR-002 ダッシュボード |

### エラーメッセージ

| 条件 | メッセージ |
|------|-----------|
| 訪問記録が0件 | 訪問記録を1件以上入力してください |
| 顧客未選択 | 顧客を選択してください |
| 訪問内容未入力 | 訪問内容を入力してください |
| 当日分の日報が既に存在する | 本日の日報は既に作成されています |

## SCR-004：日報詳細・編集画面

### 概要
日報の詳細を表示し、作成者本人は編集可能。上長はProblem・Planへのコメントを投稿できる。

### 表示条件
- ログイン済み状態
- 営業：自分が作成した日報のみ閲覧・編集可
- 上長：配下営業の日報を閲覧・コメント可

### 画面レイアウト

```
┌─────────────────────────────────────────────────────┐
│  営業日報システム        [ユーザー名] [ログアウト]   │
├─────────────────────────────────────────────────────┤
│  日報詳細  2026-04-13  山田 太郎                    │
│                               [ 編集する ] ※作成者のみ表示│
│                                                     │
│  ▼ 訪問記録                                         │
│  ┌──────────────────────────────────────────────┐   │
│  │ # │ 顧客名       │ 訪問内容                   │   │
│  ├──────────────────────────────────────────────┤   │
│  │ 1 │ 株式会社A    │ 新製品の提案を実施。先方に  │   │
│  │   │              │ 概ね好感触を得た。          │   │
│  │ 2 │ 株式会社B    │ 定期訪問。次回商談の日程調  │   │
│  │   │              │ 整を行った。               │   │
│  └──────────────────────────────────────────────┘   │
│                                                     │
│  ▼ 今日の課題・相談（Problem）                       │
│  株式会社Aの見積もり条件について上長に確認したい。   │
│                                                     │
│  💬 上長コメント                                     │
│  ┌──────────────────────────────────────────────┐   │
│  │ 鈴木部長  2026-04-13 18:30                    │   │
│  │ 見積もりは標準条件で対応してください。           │   │
│  └──────────────────────────────────────────────┘   │
│  ※上長のみ表示                                      │
│  [ コメントを入力...                          ] [投稿]│
│                                                     │
│  ▼ 明日やること（Plan）                              │
│  株式会社Aへ見積書を送付する。                       │
│                                                     │
│  💬 上長コメント                                     │
│  ┌──────────────────────────────────────────────┐   │
│  │ （コメントなし）                               │   │
│  └──────────────────────────────────────────────┘   │
│  ※上長のみ表示                                      │
│  [ コメントを入力...                          ] [投稿]│
└─────────────────────────────────────────────────────┘
```

### 項目定義

| 項目名 | 種別 | 説明 |
|--------|------|------|
| 対象日・氏名 | テキスト（表示のみ） | ヘッダーに表示 |
| 編集するボタン | ボタン | 日報作成者のみ表示。押下で各項目が編集可能になる |
| 訪問記録 | テーブル（表示のみ） | 顧客名・訪問内容を表示 |
| Problem | テキスト（表示のみ） | 課題・相談内容 |
| Plan | テキスト（表示のみ） | 明日やること |
| コメント一覧（Problem/Plan） | リスト | 上長名・投稿日時・内容を表示 |
| コメント入力欄 | テキストエリア | 上長のみ表示・入力可 |
| 投稿ボタン | ボタン | 上長のみ表示 |

### アクション

| アクション | 処理 | 遷移先 |
|-----------|------|--------|
| 編集するボタン押下 | 各フィールドを編集モードに切り替え | SCR-004（編集モード） |
| 保存するボタン押下（編集モード） | 日報・訪問記録を更新 | SCR-004（表示モード） |
| キャンセルボタン押下（編集モード） | 変更を破棄して表示モードに戻る | SCR-004（表示モード） |
| 投稿ボタン押下（成功） | COMMENTをDB保存、コメント一覧を更新 | SCR-004（再描画） |
| 投稿ボタン押下（失敗） | エラーメッセージ表示 | SCR-004（再表示） |

### 表示制御

| ユーザー種別 | 操作権限 |
|-------------|---------|
| 営業（作成者） | 日報の編集可。コメント欄は表示のみ |
| 上長 | 日報は閲覧のみ。Problem・Planへのコメント投稿可 |
| 上長以外の他ユーザー | アクセス不可 |

### エラーメッセージ

| 条件 | メッセージ |
|------|-----------|
| コメント未入力で投稿 | コメントを入力してください |
| コメントが2000文字超 | コメントは2000文字以内で入力してください |

├─────────────────────────────────────────────────────┤
│  営業マスタ                       [ + 新規登録 ]    │
